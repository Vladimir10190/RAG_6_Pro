# Техническое задание: RAG-помощник HelpDesk Cloud

## Цель и результат

Локальное веб-приложение отвечает на русском языке на вопросы о HelpDesk Cloud по Markdown-документам из `БЗ`. Каждый ответ сопровождается названиями документов и разделов. Если база не подтверждает ответ, приложение сообщает об отсутствии информации.

## Функциональные требования

- Python backend на FastAPI предоставляет `POST /api/chat` и статическую веб-страницу чата.
- Индексатор извлекает Markdown-разделы по заголовкам, сохраняет таблицы и связанные абзацы в одном чанке, добавляет источник (имя файла и раздел) и строит embeddings OpenAI.
- FAISS хранит локальный векторный индекс; повторный запуск команды индексации заменяет его актуальной версией.
- Каждый запрос получает embedding, выполняет поиск по FAISS и передаёт только подходящие чанки модели OpenAI. Ответ ограничен содержимым источников; при недостатке контекста модель должна воздержаться от ответа.
- API возвращает текст ответа, источники и `no_answer`. Веб-чат показывает состояние загрузки, ошибки, историю текущей страницы и источники.
- API-ключ, необязательный базовый URL OpenAI-совместимого провайдера (в том числе агрегатора) и имена моделей задаются переменными окружения. Ошибки конфигурации и API отображаются понятным сообщением.

## Интерфейс

`POST /api/chat`, JSON: `{ "question": "..." }`. Успешный ответ: `{ "answer": "...", "sources": [{ "document": "...", "section": "..." }], "no_answer": false }`. Пустой вопрос получает HTTP 422. Недоступная конфигурация или ошибка провайдера — понятный HTTP 503.

## Приёмка

Проверить восемь заданных вопросов, перефразировки, отсутствующий в базе факт, пустой ввод, отсутствие ключа/API, корректность источников и переиндексацию изменённого документа. Для RAG в рабочем режиме обязательны реальные embeddings и FAISS; совпадения по ключевым словам не заменяют семантический поиск.

## Ограничения и допущения

Локальное учебное использование без регистрации и облачного развёртывания. OpenAI API используется для embeddings и генерации; ключ предоставляется оператором. Сведения и тарифы HelpDesk Cloud учебные и вымышленные.
