# Рабочие пространства и группы

Все сведения в этом документе относятся к вымышленному учебному сценарию HelpDesk Cloud.

## Группы обработки
Администратор может создать группу в разделе «Настройки → Группы → Создать группу». Для группы указываются название и участники. Одна учетная запись может входить в несколько групп.

## Назначение заявки группе
При создании или редактировании заявки выберите группу в поле «Группа». Исполнителя можно назначить из участников выбранной группы. Смена группы сама по себе не отправляет ответ клиенту.

## Отсутствие исполнителя
Если подходящего исполнителя нет в списке, проверьте его членство в группе и активность учетной записи. Изменить состав группы может администратор.
