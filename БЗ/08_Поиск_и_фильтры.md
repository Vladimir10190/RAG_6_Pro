# Поиск заявок и фильтры

## Быстрый поиск
Строка поиска принимает номер заявки (например HD-1042), тему и email клиента. Поиск по содержимому переписки работает только для последних 90 дней.

## Фильтры
Доступны статус, приоритет, исполнитель, группа, дата создания и теги. Несколько выбранных фильтров объединяются логическим И.

## Сохраненные представления
Заявки → Фильтры → Сохранить представление. Личные представления видит автор, общие — вся команда; создать общее может администратор.

## Нет результатов
Сбросьте фильтры, проверьте рабочее пространство и дату. Архивные заявки старше 365 дней доступны только через экспорт администратора.
