# REST API и ограничения

## Доступ
Администратор создает токен: Настройки → API → Создать токен. Передавайте заголовок Authorization: Bearer TOKEN. Токен показывается только один раз.

## Методы
GET /api/v1/tickets — список заявок; GET /api/v1/tickets/{id} — карточка; POST /api/v1/tickets — создание; PATCH /api/v1/tickets/{id} — изменение.

## Лимиты
100 запросов в минуту на токен. При превышении возвращается HTTP 429 и заголовок Retry-After в секундах. Максимум 100 элементов на страницу; пагинация через page и per_page.

## Ошибки
401 — недействительный токен; 403 — нет прав; 404 — объект не найден; 422 — неверные поля; 500 — внутренняя ошибка.

API-адреса в учебном комплекте условные; реального сервера нет.
