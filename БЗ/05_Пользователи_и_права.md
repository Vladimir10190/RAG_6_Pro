# Пользователи и права доступа

## Приглашение
Администратор: Настройки → Пользователи → Пригласить → email → роль → Отправить. Приглашение действует 7 дней.

## Матрица доступа
| Действие | Администратор | Оператор | Наблюдатель |
|---|---|---|---|
| Просмотр заявок | Да | Да | Да |
| Ответ клиенту | Да | Да | Нет |
| Изменение SLA | Да | Нет | Нет |
| Управление пользователями | Да | Нет | Нет |
| Экспорт данных | Да | Нет | Нет |

## Удаление пользователя
Администратор деактивирует учетную запись. Заявки сохраняются и должны быть переназначены вручную. Удаление пользователя не удаляет историю переписки.
