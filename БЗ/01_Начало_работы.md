# Начало работы с HelpDesk Cloud

Продукт: HelpDesk Cloud, учебный SaaS для обработки заявок. Версия документа: 1.0.

## Первый вход
1. Откройте https://demo.helpdesk-cloud.example (вымышленный адрес, не рабочий сайт).
2. Введите корпоративный email и пароль, полученные от администратора.
3. Подтвердите email по письму. Ссылка действует 24 часа.
4. Создайте рабочее пространство: Настройки → Организация → Создать.
5. Укажите название и часовой пояс; по умолчанию Europe/Moscow.

## Роли
Администратор управляет пользователями и тарифом. Оператор обрабатывает заявки. Наблюдатель только читает.

## Ограничения
Один email может состоять в нескольких рабочих пространствах. Для переключения используйте меню профиля → Рабочее пространство.
